# R23 Editable test edition
Edit wedding-config.js only for supported settings. Existing foreground arrays accept src, left, top, displayWidth, displayHeight, opacity, fit and visible. Background paths and backgroundStyle are per step. CSS image paths are in cssImages. Music uses assets/music/wedding.mp3 (supply your own file). Text entries retain original artwork when unchanged; changed text uses HTML and, for embedded text, a replacement patch. Patch crops are approximate and may show seams; moving embedded text may require a custom clean patch. Step 3 photographs and some combined icon artwork remain flattened and cannot be independently edited without source layers. Do not deploy without visual testing. Original images were not recompressed.
